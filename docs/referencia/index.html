Referência da API

Endpoints oficiais do OkCMS. Todos os caminhos estão sob /api/v1, exceto os wells-known.

Autenticação

Método Endpoint Descrição
POST /api/v1/auth/login Autentica usuário e retorna JWT assinado com RS256
POST /api/v1/auth/api-key Cria ou rotaciona API Keys de serviço

JWKS (JSON Web Key Set)

Método Endpoint Descrição
GET /.well-known/jwks.json Retorna chaves públicas ativas para validação de JWT

As chaves rotacionam automaticamente. Clientes devem buscar o JWKS periodicamente e fazer cache por kid.

Collections

Método Endpoint Descrição
GET /api/v1/collections/:nome Lista itens (paginado, com filtros)
POST /api/v1/collections/:nome Cria um novo item
GET /api/v1/collections/:nome/:id Obtém um item por ID
PATCH /api/v1/collections/:nome/:id Atualiza item parcialmente
DELETE /api/v1/collections/:nome/:id Remove item (soft delete quando suportado)

Autenticação obrigatória

Requisições que modificam dados exigem header Authorization: Bearer <token> ou X-API-Key. O contexto do tenant é injetado automaticamente a partir da sessão autenticada.
